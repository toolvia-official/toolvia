Toolvia Project

طريقة التشغيل:
1) فك الضغط.
2) افتح فولدر Toolvia-Project.
3) افتح الفولدر ببرنامج VS Code.
4) افتح index.html.
5) اضغط Go Live أسفل يمين VS Code.

الملفات:
index.html = هيكل الموقع
style.css = التصميم
script.js = الأدوات والتفاعل

ملاحظة: أداة العملات الحية غير موجودة لأن سعر العملة يحتاج API. باقي الأدوات تعمل داخل المتصفح.
